Analysis scope and limitations

For known transfer accesses, the analyzer checks for a memory dependency with matching access scopes for Write -> Read (RAW) and Write -> Write (WAW), and an execution dependency for Read -> Write (WAR).

This RenderDoc XML does not record which buffers a Dispatch accesses or whether the shader reads or writes them. Dispatches are shown as access unknown and excluded from automatic analysis. Dependency checks are limited to vkCmdCopyBuffer commands in the same command buffer. This is not a complete Vulkan synchronization validation; resource aliasing, out-of-range shader accesses, synchronization between queues, and layout transitions are not fully checked.
